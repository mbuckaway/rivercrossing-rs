# CODINGSTANDARDS-UX-DESKTOP.md — rivercrossing-rs (egui)

Companion to `CODINGSTANDARDS-UX.md` (the neutral UX core). The desktop app is **egui**
(custom-drawn, immediate-mode), so the wx/XRC/native-control rules of the Python version do not
apply; the **product UX contract** carries over unchanged.

## Keyboard-first

- Every command is keyboard-reachable through a registered `Action`/command id.
- Single-source shortcut table, with `Command` vs `Ctrl` abstracted by platform; the Keyboard
  Shortcuts dialog is **generated by iterating the `Action` registry**.
- Never steal focus mid-keystroke — buffer the plate input, never re-request focus while typing.
- Never bind a destructive action to a bare unmodified key.

## Command / Action registry (replaces XRC frozen names + `ids.py`)

- The §15 menu map and §15b frozen-name registry become one `Action` enum/registry: stable string id,
  human label, shortcut, `enabled()` predicate, and target (open window / open dialog / fire command).
- Menu rows and on-screen buttons dispatch the **same** `Action` id — no drift.
- A CI ids-drift check fails when a frozen name appears more than once per window or is unreferenced.

## Dialogs & destructive actions

- `Esc` cancels (non-destructive); `Enter` activates the default; focus is locked within the modal.
- Destructive actions are confirm-or-time-boxed-undo, name the object, and default to the safe button.
- **Disable, never hide** unavailable commands.

## Menus, windows, DPI

- One menu tree for all platforms; About / Settings / Quit relocate to the macOS app menu.
- Minimum size verified to fit 1366×768; persist/restore window geometry against the current display.
- Resolution-aware (`pixels_per_point`); honour reduced-motion and OS text scaling.

## Accessibility

- WCAG 2.2 AA contrast; every control has a **stable id** that doubles as its screen-reader label;
  no colour-only meaning; no hover-only essential information.
